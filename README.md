# pulsex.beta-test
PULSEX ⚡ PULSEX — это легковесный и мощный оптимизатор Windows, созданный специально для геймеров. Он помогает выжать максимум FPS, снизить задержки ввода (input lag) и освободить системные ресурсы, отключая фоновые службы и настраивая параметры системы под игры — без риска для стабильности ОС.
